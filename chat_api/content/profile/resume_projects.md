# Aaron Chen Resume Projects

## Agentic Materials Discovery Platform
Period: January 2025 to present

Aaron built an LLM-driven workflow engine that converts research questions or user requests into constrained materials-screening jobs with retrieval, filtering, ranking, validation, and report generation. The platform integrates external scientific databases, machine-learning property estimation, fallback inference logic, schema validation, step-level logging, and automated tests to improve robustness and reproducibility.

## Crystal Graph Convolutional Neural Network for Electronic Property Prediction
Period: November 2020 to November 2022

Aaron built a PyTorch CGCNN model for perovskite band-gap prediction and improved accuracy by roughly 30 percent over baseline approaches. He extended the model to transfer learning and multi-property prediction for hybrid-perovskite use cases.
