# Context

## Purpose
This project is Aaron Chen's public portfolio site and chat-assisted research profile.

## Canonical Terms
- **Portfolio site**: Public React frontend deployed on GitHub Pages.
- **Chat API**: Separate backend service that answers questions grounded in Aaron's personal corpus.
- **Personal corpus**: Combined source material used by chat retrieval. Includes authored profile documents plus research papers.
- **Research projects**: Academic publications and scientific work, especially materials science, simulation, and machine-learning-for-science efforts.
- **Engineering projects**: Software builds, tooling, and AI application work outside formal paper outputs.
- **Experience**: Professional or technical capability areas described on the site. In v1, this is represented as experience themes instead of a strict employer-by-employer resume.

## Boundaries
- GitHub Pages hosts static frontend only.
- Chat generation must stay inside personal corpus scope.
- Friend's site is reference for capability, not template for visual identity.
